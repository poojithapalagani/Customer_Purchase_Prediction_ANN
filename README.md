# Customer_Purchase_Prediction_ANN

The dataset contains 100 samples and 9 columns. After removing the session_id column, 8 features were used for modeling.
The target variable is purchase, which is binary (0 = No Purchase, 1 = Purchase).
The dataset is slightly imbalanced, as the number of non-purchase instances is higher than purchase instances.
To handle imbalance, techniques such as oversampling (SMOTE) or class weighting can be used.
